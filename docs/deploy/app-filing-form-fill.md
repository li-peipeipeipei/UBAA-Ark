### 公钥怎么从 `.cer` 里取（方法记录）

AGC 下载的 `.cer` 是 **PEM 文本，内含 3 段证书链**（根 CA → 中间 CA → 叶子证书）。直接双击只会显示第一段（根证书 Huawei CBG Root CA G2），**必须只留叶子证书**：

1. 记事本打开 `ubaa-release (1).cer`，会看到 3 段 `-----BEGIN CERTIFICATE----- ... -----END CERTIFICATE-----`。
2. 删除前两段（根 CA、中间 CA），只保留最后一段（Subject 含 `Release` 的那段）。
3. 另存为 `.cer`，双击 → 「详细信息」→「公钥」即为上面那串；切到「指纹」（SHA1）即指纹值。
4. 已帮你切好叶子证书：`C:\Users\Lipeipeipeipei\Downloads\ubaa-release-leaf.cer`，双击即可查看。

> 若华为云备案系统支持"上传 App 安装包智能检测特征信息"，可直接上传正式 release 包自动带出三项，免去手填。但注意备案用的证书必须与上架包签名一致。

## 四、两个卡点

### 卡点一：域名 + IP 关联（最可能卡住的地方）

备案的「关联的 IP 地址」不是随便填的——它只能从**华为云账号下已有的备案资源**里下拉选择（买过 ECS/轻量服务器/备案服务码才会出现）。

- 点开 IP 下拉：**有值** → 选一个，域名下拉选 `arkubaa.com`，继续。
- **下拉为空 / 选不到** → 说明该账号下没有可用备案资源，需先在华为云购买服务器或备案服务码，并把 `arkubaa.com` 解析到该 IP、完成域名实名认证（主体须与备案主体一致）。

同时注意一个事实冲突：UBAA 是**客户端直连学校系统、自建服务端已下线**，并没有用 `arkubaa.com` 做实际后台。管局审核可能核查域名是否真实使用。若审核质疑，需在备注/补充材料里说明该域名用途，或改用实际使用的域名。

### 卡点二：APP 名称一致性

备案页当前填的是 `UBAA Ark`，但项目代码里的显示名目前是 `UBAA`，图标上也烧录了 `UBAA`。三处必须统一，否则华为应用市场在备案校验环节会对不上。

- 若最终定名 `UBAA`：把备案这里的 `UBAA Ark` 改回 `UBAA`。
- 若最终定名 `UBAA Ark`：需先按 `docs/deploy/app-rename-checklist.md` 把代码资源、图标、AGC 应用名全部改过来，再提交备案。
