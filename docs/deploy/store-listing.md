## 二、详细描述（可直接复制）

> ⚠️ 已与 `docs/deploy/store-description.md` 同步（App Store 与 AGC 共用同一份长描述）。

```
UBAA 2.0 全新重构的 HarmonyOS 原生版本。

UBAA 是由北航学生开发的校园助手。它把分散在多个学校系统里的常用服务放进一个应用：查课表、看成绩、约图书馆座位、交作业，都不用再切换网站或应用。

【来源说明】
本应用基于开源项目 UBAA（github.com/BUAASubnet/UBAA）开发，由个人开发者独立维护，并已获得上游项目方同意发布。本应用不是任何学校的官方应用，与学校及相关校内系统的运营方无从属、代理或合作关系，不代表学校提供任何官方服务。UBAA 采用 MIT 许可证，本应用保留其版权声明与许可证全文。

【课表与考试】
· 周视图网格课表，左右拖动即可跟手翻周
· 同一时段多门课自动合并，点开查看完整列表
· 课表本地缓存，断网也能看上次的课表
· 考试安排：科目、时间与考场一览

【成绩与学习】
· 按学期查询各科成绩，自动汇总学分与绩点
· 空闲教室：按教学楼与日期查询教室占用情况
· SPOC 作业列表与详情，支持跳转学校网页完成提交
· 课堂签到：上课前几十秒一键完成

【博雅课程】
· 浏览课程列表与详情，查看已选课程
· 选课、退选与签到签退
· 达标情况统计

【校园服务】
· 图书馆座位：楼馆 → 分区 → 座位，查询与预约
· 我的预约，随时查看
· iHome 校园诉求工单与处理进度
· 阳光打卡记录
· 评教任务与明细查看

【桌面卡片】
· 下一节课、今日课表、本周课表
· 考试倒计时、本学期成绩、空闲教室
· 长按桌面图标即可添加，数据与应用内一致

【使用体验】
· 校园内外都能用：直连与学校 WebVPN 两种连接方式随时切换
· 手机与平板两套布局，平板端使用侧栏导航
· 基于 HarmonyOS 设计套件打造，支持沉浸光感材质

【隐私与安全】
· 所有校园请求由你的设备直接发给学校，不经过开发者的服务器
· 记住的账号信息保存在设备本地
· 仅申请网络访问与网络状态两项权限
· 无广告、无统计、无第三方 SDK

【系统要求】
需要 HarmonyOS 6.1（API 23）及以上版本的设备，支持手机与平板。

【使用须知】
· 需要用北京航空航天大学统一身份认证账号登录，适用于北航在校学生
· 课程、成绩、预约等信息以学校系统为准
· 评教、签到、预约等提交操作不可撤销，请确认后再操作
```

> ⚠️ 上游项目方要求「在应用介绍中注明该版本基于 UBAA 开发，由你独立维护」，
> 上面第二段已按此要求写明，**不要删除**。

## 三、免责声明（放在描述末尾或「关于」页）

```
本应用为第三方开源衍生版本，非学校官方应用。应用内所有数据均由用户本人通过统一身份认证登录后自行访问学校系统获得，开发者不收集、不存储、不转发任何账号与业务数据。使用本应用即表示你理解并同意：应用仅作为个人便捷访问校园服务的客户端工具，不代表学校立场，也不替代学校官方渠道。
```

| 是否含用户间社交/内容发布 | 否 |
| 是否含 AI 生成功能 | 否 |
