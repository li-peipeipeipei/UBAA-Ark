# 商店介绍图：截图抓取与合成指南

> 目标：一批带壳截图 → 程序化合成两套尺寸的商店介绍图。
> - **App Store 版**：1290×2796（iPhone 6.7"），竖版，标题在上、手机在下
> - **华为应用市场版**：1080×1920（9:16），竖版，标题在上、手机在下（AGC 手机页签规格）
>
> 两套共用同一批源截图与同一套标题文案。

## 二、合成命令

```powershell
python D:\0001\UBAA-HarmonyOS\docs\deploy\tools\make-appstore-shots.py `
  --shots D:\0001\_shots_in `
  --config D:\0001\UBAA-HarmonyOS\docs\deploy\shots-config.json `
  --out D:\0001\UBAA-HarmonyOS\docs\deploy\store-shots `
  --target all --no-frame
```

> `--no-frame` = 不额外绘制程序化机身边框（沿用原图设备外壳）。
> `--target all` = 同时输出 App Store 竖版（1290×2796）与 AGC 竖版（1080×1920）。

### 当前默认：**保留原图设备外壳**，不裁壳、不画机身

手机与平板用同一套处理（原图带壳直接贴，保留 alpha）：

| 环节 | 做法 |
|---|---|
| 载入 | `convert('RGBA')`，保留 alpha |
| 合成 | `paste(img, pos, img)`，把 alpha 当 mask —— 设备轮廓外的透明区**透出背景色** |
| 壳 | **沿用原图**，不裁壳、不额外画机身 |

> ⚠️ 早期版本裁过壳并额外画了一圈深色机身边框，结果是**两层边框叠加**，观感不对，已废弃。
> 现在手机与平板完全一致：都是原图带壳直接贴。

### `--uncase`（可选，默认不用）

裁掉黑壳边、只留屏幕内容，裁切结果为 **1316×2832**（与原机屏幕分辨率一致）。
只有当你希望「手机上不显示设备外壳、只显示界面」时才启用；它依赖黑带探测，
对 alpha 渐变边缘不敏感，检测失败会回退到整图并打印提示。

### ⚠️ 必须全程保留 alpha 通道（重要）

带壳截图是 **RGBA**，图像外圈（以及设备轮廓之外）**是透明的**。
一旦 `convert('RGB')`，PIL 会**直接丢弃 alpha**，透明像素被留成黑色 ——
贴到浅色背景上就是四个黑块。

| 环节 | 做法 |
|---|---|
| 壳边检测（启用 uncase 时） | 判「纯黑」时同时要求 `alpha > 250`，避免把透明描边误判成壳边 |
| 屏幕圆角 | **不覆盖**原 alpha（`putalpha` 会把壳残留黑角重新变不透明）；需要额外切圆角时用 `ImageChops.multiply` 与原 alpha **求交** |
| 合成 | `paste(img, pos, img)`，把 alpha 当 mask —— 轮廓外的透明区**透出背景色** |

不加 `--uncase` 时，脚本会把带壳图原样贴上（黑角保留），或用纯截图画机身。

### 其他参数

| 参数 | 作用 |
|---|---|
| `--no-frame` | 不画机身，纯屏幕直接贴（用于已是纯截图的素材） |
| `--target appstore\|agc\|both` | 选输出规格，默认 both |
| `--fill-notch` | 抹除状态栏上方的模板挖孔装饰（默认**不抹**，保留真机三挖孔） |

## 三、标题文案（`shots-config.json`）

| 字段 | 含义 | 约束 |
|---|---|---|
| `file` | 源截图文件名 | 必须与实际文件一致 |
| `brand` | 顶部品牌小字 | 固定「UBAA 鸿蒙版」 |
| `title` | 主标题第一行 | 粗体，≤8 字 |
| `title2` | 主标题第二行 | 粗体，≤8 字 |
| `subtitle` | 副标题 | 灰色，≤20 字 |
| `tone` | 两行的颜色顺序 | `gray-first`（深灰在上，默认）/ `blue-first`（蓝色在上） |
| `crop_bottom` | 裁掉底部比例 | 默认不用（桌面卡片图保留完整 Dock） |

> **`tone` 的作用**：6 张图并排时若全是「深灰 + 蓝」同一顺序，会显得批量生成。交替后深浅行在视觉上交错。
>
> **标题句式刻意差异化**，不要改回同一种句式（第一版全是「XX + 动作」三字排比，已废弃）：
>
> | # | 句式 |
> |---|---|
> | 1 | 陈述 + 结果（今天这几节课 / 首页直接给答案） |
> | 2 | 名词 + 动作（整周课表 / 左右一拖就翻页） |
> | 3 | 设问 + 答（还有空位吗 / 图书馆座位当场约） |
> | 4 | 口语提醒 + 动作（作业别拖到最后 / SPOC 一步跳过去） |
> | 5 | 场景 + 决策（想选的博雅 / 详情看清了再选） |
> | 6 | 对比 + 动作（不用打开应用 / 课表考试摆桌面） |

改文案只改 JSON，重跑脚本即可，不用动代码。

## 六、平板素材（AGC「平板」页签）

平板是**横屏**设备，套手机的竖版模板会很别扭，所以单出一套版式：
**1920×1280（3:2）横版画布，文字在左、平板截图在右**。

| `caseshot_1794836541549.png` | 博雅课程 |
| `caseshot_1794836514904.png` | 平板桌面（卡片 + Dock） |

### 🔑 平板**保留设备外壳**，不裁壳

与手机相反，这是两条不同的处理，原因是问题性质不同：

- **手机**：裁壳是为了消除**四角黑块** —— 壳的圆角在介绍图里成了突兀的黑角（你最初指出的问题）；
- **平板**：黑边是**一整圈设备边框**（侧边按键、圆角轮廓都在），本身就是"这是一台平板"的视觉表达，
  裁掉就退化成纯界面截图，反而丢了设备形态。

配置项 `uncase: false` 单独控制（见 `shots-config-tablet.json`），与全局 `--uncase` 解耦。

### 合成命令

```powershell
python D:\0001\UBAA-HarmonyOS\docs\deploy\tools\make-appstore-shots.py `
  --shots D:\0001\_shots_tablet `
  --config D:\0001\UBAA-HarmonyOS\docs\deploy\shots-config-tablet.json `
  --out D:\0001\UBAA-HarmonyOS\docs\deploy\store-shots-tablet `
  --target tablet --uncase
```

产出 `store-shots-tablet/*_tablet.png`（**1920×1280，3:2**，共 6 张），用于 AGC 素材管理的「平板」页签。
