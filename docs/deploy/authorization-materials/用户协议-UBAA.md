1. 本用户协议由您与开发者李沛轩（以下简称"我们"）达成协议。
2. 请在安装或使用 UBAA 前仔细阅读并接受本协议。您安装、登录、注册或使用 UBAA 任何功能，即视为您已充分理解并同意本协议以及《UBAA 隐私政策》。

1. UBAA 是面向北京航空航天大学在校学生的校园服务聚合客户端，基于开源项目 UBAA（MIT License）独立开发与维护。
2. UBAA 并非北京航空航天大学官方应用，与学校无授权、合作、背书或隶属关系。
3. 您理解并同意：UBAA 连接的学校统一身份认证、教务、图书馆、SPOC 等系统由学校或其第三方服务商独立运营，其可用性、准确性、稳定性及内容合法性由对应系统运营方负责。

## 三、用户资格与账号

1. 您应当是北京航空航天大学在校学生，且使用本人依法有权使用的学校统一身份认证账号。
2. 您应妥善保管账号和密码，并对通过您的账号发生的操作承担全部责任。因您泄露账号、借予他人使用或其他自身原因造成的损失，由您自行承担。
3. 您不得使用 UBAA 从事违法违规、侵犯他人权益、干扰学校系统正常运行、批量抓取或缓存他人数据、绕过学校安全机制的行为。

1. UBAA 通过您的设备直接访问学校系统。我们不对学校系统的可用性、数据准确性、服务中断或密码策略变更承担责任。
2. UBAA 不提供免登录演示模式。所有查询与提交操作均会真实访问学校系统；其中评教、签到、座位预约、选课退选等操作一经提交不可撤销，后果由您本人承担。
3. 您理解学校系统接口可能随时调整，导致部分功能不可用；我们会在条件允许时适配，但不承诺所有功能永久可用。
4. UBAA 不提供任何形式的担保，包括但不限于对特定用途的适用性、不中断、无错误等明示或暗示的担保。
