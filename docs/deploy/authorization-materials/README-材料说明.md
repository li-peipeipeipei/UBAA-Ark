# 授权材料清单与提交说明

本压缩包用于华为应用市场（AppGallery Connect）「版本信息 → 版权信息 →
授权书及其他材料」栏目的上传（zip 格式，≤200 MB，≤200 个文件，层级 ≤3 层，
仅支持 JPG / JPEG / BMP / PDF）。

## 一、包内已提供的文件

| 文件 | 说明 | 对应证明事项 |
| --- | --- | --- |
| `01-授权书-软件著作权授权发行书.pdf` | 授权发行书正文，**需签字后扫描替换** | 授权方许可发行方上架 |
| `02-MIT许可证-LICENSE.pdf` | 上游项目 UBAA 的 MIT 许可证全文 | 分发时保留版权声明与许可证文本 |
| `03-隐私政策.pdf` | 应用隐私政策全文 | 隐私合规，与商店隐私托管页内容一致 |
| `04-材料说明.pdf` | 本清单 | 审核快速索引 |

## 二、需要你补齐的两项（补完再上传）

| 文件 | 来源 | 格式要求 |
| --- | --- | --- |
| `05-上游同意上架邮件.pdf` | 你收到的上游项目方回复原文（同意上架、要求保留 MIT 版权与独立维护声明） | 截图转 PDF 即可 |
| `01-授权书-软件著作权授权发行书.pdf`（签字版） | 本包内的授权书打印后由双方签字/盖章，扫描成 PDF 替换 | 签名须手写或盖章 |

> 授权书若只由被授权方单方签字，审核可能要求补授权方签字。**优先两边都签**；
> 若上游不便签字，可附上游邮件原文作为替代佐证，并在授权书备注栏说明。

## 三、补充说明（可在授权书末尾另附一页）

1. 被授权软件名称为「UBAA」，与华为应用市场创建的应用名称、包名 `com.ubaa.app` 一致。
2. 被授权软件无自建服务端，账号与业务数据由用户设备直连学校统一身份认证系统获取，
   不上传至开发者或任何第三方服务器。
3. 被授权软件仅申请网络访问与网络状态两项权限，无广告、无统计、无第三方 SDK。
4. 被授权软件不含 AI 生成合成功能，不含应用内商品与内购。
5. 本次申请的软件著作权登记证书主体与工信部备案主办单位名称保持一致。
