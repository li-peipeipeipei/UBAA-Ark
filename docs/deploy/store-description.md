## 四、写法上的三个刻意选择

1. **不写鸿蒙版没有的功能**。iOS 版有日程待办、北航云盘、财务收入查询、匿名统计、自动连接切换，
   鸿蒙版一律没有。照抄会构成申报不实。
2. **连接方式写「随时切换」而非「自动切换」**。鸿蒙版是手动在直连 / WebVPN 间切换，
   两种模式的会话 Cookie 相互隔离，切换后需重新登录 —— 这点已写进使用须知。
3. **「评教」只写「任务与明细查看」，不写「一键自动提交」**。鸿蒙版确有批量提交能力，
   但在商店文案里强调「自动代提交问卷」容易触发审核对代用户操作的质疑；
   实际能力在【使用须知】以「提交操作不可撤销」统一约束。
