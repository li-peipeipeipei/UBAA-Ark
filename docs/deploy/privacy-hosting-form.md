## 7. 信息存储地点及期限

### ⚠️ 7.1 固定存储期限 —— 必须改写

模板默认文案是「例如：电话号码、账号仅保存 3 年」，那是**服务器存储**场景。  
本应用的个人信息**只保存在您自己的设备上**，请把默认文案改为：

```
账号凭据、会话令牌与业务缓存仅保存在您的设备本地，不上传至开发者或任何第三方服务器。
保存期限随您的登录状态与本地缓存策略存在：退出登录、清除本地缓存或卸载应用后即被删除。
```

### ⚠️ 7.2 传输并存储至服务器 —— 必须改写

模板默认是「上述信息包含传输并存储至【服务器所在国家】的服务器」，同样假设开发者有服务器。  
本应用的情况是：

```
上述个人信息不传输至开发者或任何第三方服务器。您的设备在您主动发起查询或操作时，
直接与北京航空航天大学统一身份认证及教务系统通信，相关服务器位于中国境内。
```

> 若该字段强制要填「服务器所在国家」，填 **中国境内**（学校系统所在地）。
